# Util Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Option+Tab ile pencere bazlı, önizlemeli geçiş ve Cmd+Shift+V ile şifreli, aranabilir clipboard geçmişi sunan native macOS menü çubuğu uygulaması.

**Architecture:** SwiftPM paketi: `UtilCore` (şifreleme, depolama, kısayol, izin, panel yerleşimi), `ClipboardFeature`, `SwitcherFeature` kütüphaneleri ve bunları birleştiren `Util` executable'ı. Saf mantık (geçmiş, durum makinesi, yerleşim, MRU, filtre) sistem API'lerinden ayrı dosyalarda ve birim testli; sistem entegrasyonu (event tap, AX, ScreenCaptureKit, SkyLight) ince sarmalayıcılar ve elle doğrulama. `.app` paketi `scripts/build-app.sh` ile kurulur ve Yumo Teknoloji sertifikasıyla imzalanır.

**Tech Stack:** Swift 6 (dil modu 6), SwiftPM, AppKit + SwiftUI (`NSPanel` + `NSHostingView`), Observation, CryptoKit, Security (Keychain), Carbon (`RegisterEventHotKey`, TIS), CoreGraphics event tap, Accessibility (AXUIElement), ScreenCaptureKit, ServiceManagement (`SMAppService`), Swift Testing. Üçüncü parti bağımlılık yok.

**Spec:** `docs/superpowers/specs/2026-11-05-util-design.md`
